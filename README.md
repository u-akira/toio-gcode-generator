# toio G-code Generator / Pen Plotter

toio 2 台を使ったペンプロッター用の静的 Web アプリです。

## 使い方

1. PC の Chrome または Edge で `index.html` を開きます。
2. キャンバスにフリーハンドで線画を描きます。
3. キャリブレーション値を調整します。
4. `Simulate` を実行します。
5. 移動用 toio とペン昇降用 toio を接続します。
6. シミュレーション成功後に `Run toio` を実行します。

Web Bluetooth は HTTPS または localhost 上で動作します。GitHub Pages にデプロイすると HTTPS で利用できます。

ローカル確認用に Node.js が使える場合は、依存なしで簡易サーバーを起動できます。

```bash
node scripts/serve.mjs 8000
```

## 実機接続の確認

toio に接続するときは、PC 版 Chrome または Edge で開いてください。Web Bluetooth は `https://` または `http://localhost` / `http://127.0.0.1` でのみ使えます。

`Web Bluetooth API globally disabled.` が出る場合は、アプリではなくブラウザ側で Web Bluetooth が無効です。次を確認してください。

1. PC の Bluetooth がオンになっているか。
2. Chrome / Edge の最新版を使っているか。
3. GitHub Pages などの `https://`、または `http://127.0.0.1:8000/` で開いているか。
4. Chrome の場合は `chrome://flags/#enable-web-bluetooth`、Edge の場合は `edge://flags/#enable-web-bluetooth` が無効化されていないか。
5. 会社や学校の PC では、管理ポリシーで Web Bluetooth が無効化されていないか。
6. Windows の設定で Bluetooth デバイスの検出が許可されているか。

管理ポリシーで無効化されている場合、ブラウザ設定だけでは直せないことがあります。その場合は別の PC や管理されていない Chrome / Edge 環境で確認してください。

2 台の toio は BLE 選択画面で見分けづらいことがあります。移動用と昇降用を逆に選んだ場合は、接続し直さずに `役割入替` ボタンで入れ替えられます。実行前に `Pen Up` / `Pen Down` で昇降用だけが動くことを確認してください。

`Run toio` は、移動用 toio の Position ID が取得できている場合だけ実行できます。移動用 toio がプレイマット外にいる、クリアホルダー越しに読み取れていない、またはマットから浮いている場合は、目標移動できません。画面上に赤い実機 toio 表示が出てから実行してください。

`Run toio` 実行中は、移動用 toio へ送る目標座標をログに表示します。動かない場合は、直前の `toio move` / `toio rotate` の `x`, `y`, `θ`, `speed` と、その後に出る `toio target ... failed` の内容を確認してください。`0x02` は Position ID 未取得、または指定座標へ到達できない状態です。画面の Position ID が `Position ID missed` のときは、古い位置では実行せず、赤い実機 toio 表示が再表示されてから実行してください。

## プレイマット座標

画面表示、描画データ、シミュレーション、実機実行は、toio コア キューブ単体付属の簡易プレイマット Position ID 座標で扱います。範囲は左上が `x=98, y=142`、右下が `x=402, y=358` です。

シミュレーション画面には `image/` に置いたプレイマット画像を背景として表示します。実機 toio から取得した Position ID も同じ座標系なので、マット中央付近に置いたときは画面上でも背景画像の中央付近に赤い実機 toio が表示されます。

## GitHub Pages

依存ライブラリやビルド手順はありません。GitHub Pages の Source をリポジトリ root に設定すれば、`index.html` がそのまま公開されます。

## テスト

Node.js の標準テストランナーを使います。追加ライブラリは不要です。

```bash
node --test
```

主に次の中核処理をテストします。

- `plotter-core.js`: キャリブレーション設定を変えたときに、toio 軌跡、線分数、pen up/down 回数、安全領域判定が変わること。
- `toio-ble.js`: toio のモーターコマンド生成、Position ID 通知パース、目標移動レスポンスのパース。

## キャリブレーション設定

キャリブレーション値はブラウザの `localStorage` に保存されます。同じブラウザで開く限り、次回以降も前回の値が復元されます。

最初はペンを上げた状態で、短い線を描いて `Simulate` し、toio の移動範囲と向きを確認してから実機実行してください。

### 基本設定

- `安全領域`: A3 簡易プレイマット中央のうち、描画に使う割合です。初期値は `0.75` です。端で機構が干渉する場合は小さくします。
- `初期向き °`: 基準姿勢の初期値です。現在のシミュレーションでは、各線分の進行方向から描画時の toio 向きを自動計算し、向きを変える前に必ずペンを上げます。
- `ペン前後 X`: 移動用 toio の報告位置から見たペン先の前後オフセットです。toio の前方がプラス、後ろがマイナスです。ペンホルダーが toio の後ろにあるため、初期値は `-48` です。
- `ペン左右 Y`: 移動用 toio の報告位置から見たペン先の左右オフセットです。横ではなく後ろにペンがある機構では、まず `0` から調整します。
- `回転中心 X` / `回転中心 Y`: 実効回転中心の補正値です。向き変更や姿勢補正時にペン先位置がずれる場合に調整します。
- `描画速度`: ペンを下げて描くときの移動速度です。線が乱れる場合は小さくします。
- `移動速度`: ペンを上げた状態で移動するときの速度です。初期調整中は描画速度と同じか、少し速い程度にします。
- `Timeout 秒`: toio の目標移動コマンドの待ち時間です。長い移動でタイムアウトする場合は大きくします。

### 線の処理

- `平滑化`: フリーハンド線の手ブレを減らす強さです。大きくすると滑らかになりますが、線のクセや角が弱くなります。
- `点間隔`: 近すぎる入力点を間引く距離です。大きくするとコマンド数が減りますが、細部が粗くなります。
- `角検出 °`: 角として残す方向変化のしきい値です。小さくすると角を残しやすく、大きくするとより滑らかになります。
- `直線補正`: `1` で有効、`0` で無効です。フリーハンド線を少数の直線に近似し、pen up/down と回転回数を減らします。
- `補正強度`: 大きいほど元の線からのズレを許容し、少ない直線になります。
- `最小線分`: 短すぎる線分を統合する目安です。大きくすると細かい折れが減ります。

### ペン昇降

ペン昇降用 toio は、短時間のモーター駆動でペンを上げ下げします。

- `Up 速度`: ペンを上げる方向のモーター速度です。
- `Up ms`: ペンを上げるモーター駆動時間です。
- `Down 速度`: ペンを下げる方向のモーター速度です。
- `Down ms`: ペンを下げるモーター駆動時間です。
- `昇降方式`: `0` は左右モーター同方向、`1` は左右モーター逆方向です。現在の機構では `0` を使い、`Pen Up` は後退、`Pen Down` は前進させます。
- `待ち ms`: ペン上げ下げ後、機構が落ち着くまで待つ時間です。

`Pen Up` / `Pen Down` ボタンで単独動作を確認し、ペン先が確実に浮く・接地する最小の速度と時間を探します。`Pen Up` は負の速度で後退、`Pen Down` は正の速度で前進が基本です。強すぎる設定は機構やペン先に負荷をかけるため、低めの値から調整してください。

### 推奨調整手順

1. `Pen Up` / `Pen Down` で昇降設定を決めます。
2. ペンを上げたまま、短い線を描いて `Simulate` します。
3. `初期向き °` とペンオフセットを確認し、ペン先と toio 本体の位置関係がシミュレーション上で合うようにします。
4. 実機をペン上げ状態で動かし、toio 本体がマット外やホルダー端に出ないことを確認します。
5. `ペン前後 X` / `ペン左右 Y` を調整し、画面上のペン先位置と実際のペン先位置を近づけます。
6. ペンを下げて、短い直線だけを低速で描きます。
7. pen up/down が多すぎる場合は `直線補正` を有効にし、`補正強度` と `最小線分` を大きくします。
8. 線が乱れる場合は `描画速度` を下げ、必要に応じて `平滑化` と `点間隔` を調整します。
9. 問題がなければ、安全領域や速度を少しずつ広げます。
