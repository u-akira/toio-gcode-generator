# toio Do SB3 template

Place the default toio Do template at:

```text
templates/toio-do-two-cubes.sb3
```

The template must be saved from toio Do and include editable blocks for both:

- `toio #1`: `moveWheelsFor`
- `toio #2`: `moveWheelsFor`

Including `stop wheels`, `wait`, and `green flag` blocks is recommended. The exporter clones those blocks, keeps the original SB3 assets, and replaces the generated command chain in `project.json`.
